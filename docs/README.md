## JSDoc generado (histórico)

Los ficheros HTML en esta carpeta (`app.js.html`, `Operacion.html`, etc.) son  
**salida antigua de JSDoc**. No se regeneran en el flujo actual y pueden estar  
desactualizados respecto a `src/`. No los use como fuente de verdad de  
configuración o URLs.

Para regenerar documentación de API en el futuro, habría que revisar `conf.js`  
y el generador; no forma parte del build de `dist/`.
