Operacion

new Operacion(nivelopt, posicion_nivelopt, lower_boundopt, upper_boundopt, cantidadOperandosopt, permitirNegativosopt, enfocadoopt, operandosopt, incognitaopt, multiplo10opt, multiplo100opt, complementarioopt, resultadoNegativoopt, decimalesopt, decimalesMaximoopt, forzarSignosopt)

Description:

  • Clase base para las distintas operaciones ( ver Suma, Resta, Multiplicacion, Division )

    Los parametro entre llaves, esta hecho para poder cargar cualquier parametro por su nombre como objeto de esta manera se podria escribir: new Operacion(10, 1, 0, 100, 4 ) ; como: new Operacion( cantidadOperandos = 4 ); sin necesidad de poner los campos anteriores
